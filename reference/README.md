# Reference — 游戏 UI 参考收录

收录现实游戏中的 UI 设计与交互参考（**不参与运行时代码**）。

子目录规划：

```text
reference/
├── games/          # 按游戏收录（游戏名.md：UI 类型/交互/动画/截图/视频/分析）
├── screenshots/    # 截图素材
├── videos/         # 视频素材
└── notes/          # 通用笔记、来源站点、模板
```

## 来源站点（持续补充）

- [Game UI Database](https://www.gameuidatabase.com/) — 游戏 UI 截图/视频库（交互 + 动效）
- [ScreenJuice](https://screenjuice.games/) — 游戏界面灵感
- [Game UI Online](https://www.gameuionline.com/) — 游戏 UI 设计案例
